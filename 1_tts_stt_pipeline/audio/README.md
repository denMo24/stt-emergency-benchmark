# Piper TTS Voices (German)

This folder previously contained several German voice models used for testing and research.

The voice model files (ONNX) are **not included in this repository**.

Due to licensing considerations, users are asked to **download the required voices themselves** and **check the licensing information published by the Piper / Rhasspy project**.

Official source:
https://huggingface.co/rhasspy/piper-voices/tree/main/de/de_DE

## Voices Used in This Project

The following voice model filenames were used:

- `de_DE-karlsson-low.onnx`
- `de_DE-pavoque-low.onnx`
- `de_DE-ramona-low.onnx`
- `de_DE-kerstin-low.onnx`

## Notes

Please ensure to:

1. **Download the models yourself** from the official source.
2. **Check the model and dataset licenses** as provided by Piper / Rhasspy.
3. Use these models only in compliance with their respective licensing terms.

No models are distributed with this repository.
